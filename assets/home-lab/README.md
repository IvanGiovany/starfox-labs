# Gvan's lab

Original artwork generated with built-in ImageGen for the homepage intro. Three separate transparent images keep the room static while small code/sprite/foliage layers animate:

| File | Delivered size | Contents |
| --- | --- | --- |
| `lab.webp` | 1536 × 512 | Desk, monitor with blank screen, headphones, books, beetle and twilight window |
| `bird.webp` | 576 × 192 | Three equal square frames: looking left, front and right |
| `plant.webp` | 240 × 360 | Potted plant; foliage can sway independently above the pot |

WebP quality95 with full alpha quality; all derivatives were downsampled from native generated masters, never upscaled. Combined source size about265KB before responsive delivery. The scene layout uses percentages of the 3:1 lab canvas, recorded in `lib/home-lab.ts`.

Native masters, exact prompts, asset catalog and the Codex/Claude collaboration notes are retained in the workspace's `banner-collaboration` directory outside this repository. Art is original and contains no franchise characters or logos.
